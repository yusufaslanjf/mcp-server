Choose the AI tool you use. Each integration connects to Jotform's hosted MCP services; packages can also include skills or context for common tasks.

| [OpenAI](openai/README.md) | Jotform directory connection in ChatGPT; direct MCP in Codex. | Connection guides; an OpenAI plugin package has not been added here. | [Connect](../docs/openai-setup.md) |
| [Gemini CLI](gemini/README.md) | Jotform extension. | Extension manifest and Jotform context. | [Install](../docs/gemini-setup.md) |
