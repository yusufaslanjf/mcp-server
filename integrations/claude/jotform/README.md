# Jotform for Claude

Create forms, prepare documents for signature, and build apps with Jotform in Claude. Combine Forms, Sign, and Apps for client onboarding and event management.

## Get started

Follow the [Claude setup guide](https://github.com/jotform/mcp-server/blob/master/docs/claude-setup.md) to install the plugin and connect your Jotform account.

## Try it

- "Create a customer feedback form with a rating and an optional comment."
- "Create a client onboarding form and add it to a new client portal."
- "Prepare a service agreement draft using these terms."
- "Create a workshop registration form and an event app containing that same form, the schedule, and venue details."
- "What did people answer on my feedback form this week?"

## Included skills

| Skill | Use it to |
| --- | --- |
| [`jotform-forms`](skills/jotform-forms/SKILL.md) | Create and edit forms, and explore responses. |
| [`jotform-sign`](skills/jotform-sign/SKILL.md) | Prepare signing documents and track signatures. |
| [`jotform-apps`](skills/jotform-apps/SKILL.md) | Build and update client portals and event apps. |
| [`onboarding-and-events`](skills/onboarding-and-events/SKILL.md) | Combine Jotform products for client onboarding and events. |

## Data

The plugin connects Claude to Jotform's hosted services. Your Jotform account manages authentication, permissions, and stored forms, documents, and apps.
