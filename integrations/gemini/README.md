# Jotform for Gemini CLI

The Jotform extension connects Gemini CLI to the forms and submissions service and includes context for working with your account.

**[Install and connect](../../docs/gemini-setup.md)** · [Explore the MCP service](../../docs/mcp/README.md)

## Extension files

- [gemini-extension.json](../../gemini-extension.json) — package identity and MCP connection.
- [JOTFORM.md](../../JOTFORM.md) — context loaded by the extension.

These files live at the repository root, where Gemini CLI discovers the extension when installing from the repository URL.
